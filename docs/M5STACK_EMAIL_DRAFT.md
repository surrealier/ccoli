Subject: ccoli — an open-source PC-powered voice agent for ATOM Echo

Hi M5Stack team,

I built ccoli, an open-source project that turns ATOM Echo into a personal voice agent.

The setup is simple:
ATOM Echo microphone/speaker ↔ USB or Wi-Fi ↔ PC running speech recognition, an AI agent, and text-to-speech.

It supports local or cloud AI models, personal memory and tasks, and optional Home Assistant integration. I have verified voice input and audible responses on an ATOM Echo. Easier motor setup and everyday robotics features are now being developed.

You are welcome to reference, try, or reuse the project under its existing AGPL-3.0 license:
https://github.com/surrealier/ccoli

If useful, please share it with your ATOM, AI, or community team.
